## 二、本版目标（用户需求）
1. **修 Bug（最优先）**：翻书阅读每一节只占一页，内容长就被截断，下一页直接跳到下一节（例：电机学·变压器（一）第 6 节「空载电流与励磁阻抗」第 8/12 页底部文字被切）。
   - 方案：按实际高度测量内容块，自动拆成多页；段落按行拆，图片/函数图整块挪到下一页；续页顶部显示「6. 空载电流与励磁阻抗（续）」；页数、进度条刻度、缩略气泡、目录跳转都改用新页表；旋转/字号变化时重新分页。
2. **插件系统**：声明式插件（`plugin.json` + 资源 + 可选沙箱脚本），不下载可执行代码。扩展点：主题、封面包、提示词/技能、模型供应商、开屏动画、UI 块。
   - 管理页：我的 → 插件（已安装 / 插件市场 / 从文件安装），兼容性检查（apiVersion、minApp），sha256 校验，失败回滚，禁用即完全还原。
   - 市场：仓库 `QiGai77/HandCowork` 的孤立分支 `plugins`，含 `index.json`、每个插件一个文件夹、中文《如何写插件》README、重建索引脚本。App 读 `https://raw.githubusercontent.com/QiGai77/HandCowork/plugins/index.json`，可配置 Gitee 镜像。
3. **三个插件**（发布到市场，默认不内置）：
   - **识别优化**：针对语音转录的技能包。规则清洗（嗯/啊/呃/那个/这个/就是说/然后呢/对吧…，口吃重复「这个这个」，自我更正「不对，是…」，闲聊折叠）＋ LLM 精炼（老师的结论、定义、公式、例子、「这个要考/重点」等考点信号，术语保持原样），输出精炼稿＋要点；用于上课中学长模式显示和笔记生成输入；精炼强度 轻/中/强。参考开源：CapsWriter-Offline、FunASR 标点/ITN、WhisperX 等转录清洗做法（注意许可证并在 README 注明）。用户原话：现在转录“太磨叽、没说到重点”。
   - **墨韵江南**：水墨风主题。宣纸纹理底、上下淡墨山水、配色 墨黑 #2B2B2B / 黛青 / 烟灰 / 朱砂 #B5442E，霞鹜文楷（OFL），印章式按钮、毛笔进度条、线装书水墨封面 6–10 张。**参考开源**：SVG feTurbulence+位移滤镜做墨晕、水墨着色器、「中国色」色板、CC0 水墨纹理，只用 CC0/OFL/宽松许可素材并注明出处。
     - **开屏动画**（用户追加）：墨滴在宣纸上晕开 → 远山淡入 → 「课堂学长」笔刷写出 → 朱砂印落下，约 2 秒，点击跳过，尊重减少动效设置，仅在插件启用时出现，Android 12+ SplashScreen 衔接 Compose 动画。开屏作为主题插件的扩展点。
   - **供应商兼容**：导入任意 OpenAI 兼容 / Anthropic / Gemini 风格供应商和上游中转（one-api/new-api）。Base URL、接口风格、鉴权头格式、/models 拉取或手填、能力标记（对话、识图、生图、语音转写、向量）、自定义请求头、配置 JSON 导入导出；预设 DeepSeek、Kimi、硅基流动、智谱、通义兼容模式、OpenRouter、Ollama。密钥只存本地安全存储，不进插件文件和备份。
