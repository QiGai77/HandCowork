## 课堂学长 (HandCowork) v0.0.7.9 更新日志

### 💡 核心功能：智能复习卡「艾宾浩斯记忆流」与期末「考前速记冲刺」
- **艾宾浩斯记忆流预测**：复习卡片打分动态展示推荐间隔（忘了 · 10m、模糊 · 1d、记得 · 3d/7d/15d/30d/60d），科学对抗遗忘曲线。
- **动态熟练度计数器**：复习卡精准记录连续答对轮次与到期时间戳，向下兼容全部历史课堂卡片 JSON 结构。
- **期末考前速记冲刺浓缩本**：复习界面右上角一键聚合全课程卡片与关键考点（[r:考点]），生成精美 Markdown 速记文档直接写入剪贴板，考前冲刺无忧！

### 🧩 全新官方插件
- **插件 4：skill-stem-formula (理工科学长公式与代码强化)**
  - 智能校正课堂录音语音识别中的口语化数学与物理符号（如 西格玛 → \sum、偏导数 → \partial、拉普拉斯 → \mathcal{L}），自动优化代码块与算法伪代码展示。
- **插件 5：	heme-dark-star (暗夜星芒极夜黑主题)**
  - 采用 OLED 极黑底色（#0E1014）搭配星芒金（#FFD166）与极光冰蓝（#4CC9F0），高对比度护眼自习体验。
